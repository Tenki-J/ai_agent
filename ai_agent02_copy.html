08 — CLI · GitHub · Antigravity 준비

CLI 개요

Command Line Interface는 텍스트 명령으로 프로그램을 직접 제어하는 방식입니다.

기본 구조

[도구] [명령] [--옵션] [인수]

세 가지 핵심 도구

1. Claude Code

파일 편집, 코드 실행, MCP, Skill 실행 담당. 자동화와 스크립팅에 적합. Hooks, Skills, MCP 고급 기능 지원.

2. GitHub CLI

저장소, PR, 이슈를 터미널에서 관리.

3. Antigravity CLI

터미널에서 Google Antigravity에 직접 질문.

💡 세 도구를 조합하면 "저장소 상태를 확인하고, 외부 AI에게 의견을 묻고, 그 결과를 Skill 자동화로 이어가는 파이프라인"을 만들 수 있습니다.

GitHub 설정

  • 가입: github.com/signup
  • 설치 (Windows): winget install GitHub.cli
  • 설치 (macOS): brew install gh
  • 인증 확인: gh auth status

스코프 지정 인증

gh auth login --scopes repo,delete_repo,workflow,gist,read:org,admin:public_key,write:packages

GitHub CLI 기본 명령어

gh repo list      # 저장소 목록
gh pr list        # PR 목록
gh issue list     # 이슈 목록

Claude 요청 예시

설치

curl -fsSL https://antigravity.google/cli/install.sh | bash

기본 사용법

01 — 엑셀 · 워드 · PPT · 한글 문서 자동 작성

개요

Python 기반 Skill을 통해 엑셀, 워드, PPT, 한글 문서를 자동 생성하고 하나의 에이전트 명령으로 통합 파이프라인을 구성합니다.

핵심 라이브러리

라이브러리포맷용도
openpyxl.xlsx엑셀 데이터 분석
python-docx.docx워드 보고서 생성
python-pptx.pptxPPT 발표자료 생성
python-hwpx.hwpx한글 문서 생성
 
pip install openpyxl python-docx python-pptx python-hwpx

BASIC 01 — 엑셀 분석 Skill

목표: openpyxl로 매출 템플릿을 읽고 월별 통계 계산

핵심 코드

wb = load_workbook('매출데이터_템플릿.xlsx')
ws = wb['매출 데이터']
for row in ws.iter_rows(min_row=5, values_only=True):
    print(row)

실습 단계

  1. 템플릿 다운로드 후 데이터 5건 이상 입력
  2. "월별 합계와 평균 분석" 요청
  3. 최대 거래처와 평균 매출액 확인

Claude 요청 예시

openpyxl 설치하고 엑셀 파일 읽는 Skill 만들어줘

BASIC 02 — 워드 보고서 Skill

목표: python-docx로 템플릿의 플레이스홀더를 분석 결과로 자동 치환

핵심 코드

doc = Document('보고서_템플릿.docx')
for p in doc.paragraphs:
    if '[보고서 제목]' in p.text:
        p.runs[0].text = '실제 보고서 제목'
doc.save('out.docx')

처리 영역: 제목, 개요, 표, 결론

Claude 요청 예시

엑셀 분석 결과를 바탕으로 보고서_템플릿.docx 양식에 맞게 보고서 만들어줘

BASIC 03 — PPT Skill

목표: python-pptx로 9장 구조 템플릿에 맞춰 발표자료 자동 구성

핵심 코드

prs = Presentation('회사_범용_템플릿.pptx')
slide = prs.slides[3]
for shape in slide.shapes:
    if shape.has_text_frame:
        shape.text_frame.text = '새 내용'

4단계 구성

조사 (주제 웹조사 및 근거 수집) → 구성 (9장 템플릿 구조 적용) → 검토 (슬라이드 제목·본문 길이 확인) → 생성 (pptx 파일 저장)

BASIC 04 — 한글 Skill

목표: python-hwpx와 gonggong 템플릿으로 .hwpx 보고서 생성

4단계 워크플로우

  1. report-template.hwpx 복사
  2. ObjectFinder로 플레이스홀더 확인
  3. zip_replace()로 내용 변경
  4. fix_namespaces.py 실행

Claude 요청 예시

gonggong report-template.hwpx로 [주제] 보고서 만들어줘

검토: hwp.polarisoffice.com에서 설치 없이 열어 확인

PIPELINE — 4종 문서 동시 생성

엑셀 (데이터 읽기) → 워드 (보고서 채우기) → PPT (발표자료 생성) → 한글 (.hwpx 보고서 생성)

최종 에이전트 명령

매출데이터_템플릿.xlsx 읽어서 워드, PPT, 한글 보고서를 모두 동시에 만들어줘

심화

gh repo → 분석 → Skill 파일 생성

Playwright 소개

Claude (MCP Tool 호출) → Playwright 서버 (브라우저와 통신) → AI (DOM 스냅샷을 텍스트로 판단)

03 — GWS CLI로 Google Workspace 자동화

개요

Claude가 gws 명령어를 직접 실행하여 Drive, Gmail, Calendar, Sheets, Docs, Forms를 제어합니다.

설치 및 인증 단계

Step 1 gws 설치

npm install -g @googleworkspace/cli

Step 2 gcloud 인증

gcloud auth login --launch-browser

Step 3 GCP 프로젝트 설정

프로젝트 생성 후 gws auth setup 실행 (Forms API까지 활성화)

Step 4 OAuth 클라이언트 생성

동의 화면, 테스트 사용자, 클라이언트 ID 생성

Step 5 환경 파일 저장

~/.config/gws/.env

Step 6 최종 스코프 인증

gws auth login -s drive,gmail,calendar,sheets,docs,forms

인증 확인 및 핵심 명령 패턴

# 상태 확인
gws auth status

# Drive 테스트
gws drive files list --params '{"pageSize":5}'

# Gmail 읽기
gws gmail messages list --params '{"q":"is:unread"}'

# Calendar 조회
gws calendar events list --calendarId primary

Skill 문서화

gws CLI 사용법 정리해서 gws_skill.md Skill 문서로 만들어줘.
인증 정보(CLIENT_ID 등)는 .env 파일 연결로, Skill만으로 바로 쓸 수 있게 구성해줘

실습 4종

서비스자연어 명령
Drive"내 드라이브 최근 파일 5개 목록 보여주고, 텍스트 파일 하나 만들어서 업로드해줘"
Gmail"안 읽은 메일 3개 요약해주고, 나한테 실습 완료 메일 보내줘"

04 — 외부 API로 AI 기능 확장

API 키 발급 기본 흐름

회원가입 → 개발자 콘솔 접속 → 키 생성 → 복사

네이버 오픈 API와 데이터랩 Skill

사용 API

  • 검색어 트렌드 API: 최대 5개 키워드 비교 (시장 조사, 마케팅 분석)
  • 쇼핑인사이트 API: 카테고리별 클릭 트렌드 (제품 수요 분석)

앱 등록 단계

  1. developers.naver.com/apps/#/list 접속
  2. 애플리케이션 등록 클릭
  3. 이름 입력 (예: naver-datalab-skill)
  4. 데이터랩(검색어트렌드)과 데이터랩(쇼핑인사이트) 체크
  5. 환경: Web, URL: http://localhost:3000
  6. Client ID와 Client Secret 복사

환경변수 보관

NAVER_CLIENT_ID=발급받은_클라이언트_ID
NAVER_CLIENT_SECRET=발급받은_시크릿

05 — Notion DB + 에이전트 연결

핵심 목표

Notion DB + API 연결을 완성해 Claude가 DB 구조를 파악하고, Status가 '할일'인 항목을 조회하며, 샘플 데이터까지 채우는 자동화 흐름을 만듭니다.

Notion의 역할: 외부 기억 장치

  • API 공개로 AI가 직접 읽고 쓸 수 있음
  • 문서 + 스프레드시트 + DB + 칸반 통합 관리
  • Status 필터로 AI가 자동 조회, 파이프라인 연결 가능

Notion MCP vs Notion API

방식특징용도
Notion MCP대화 중 직접 연결, 별도 코드 불필요빠른 테스트, 간단한 읽기/쓰기
Notion APIPython 코드로 직접 호출, DB 필터·정렬·페이지네이션 자유로움자동화 스크립트, 반복 호출, 일괄 수정

이번 수업 방식: API 토큰 발급 → notion-query 스킬 제작

API 토큰 발급 단계

Step 1 Integration 생성

  1. notion.so/my-integrations 접속
  2. + New integration 클릭
  3. 이름 입력 (예: my-agent)
  4. Submit 후 Internal Integration Token 복사 (secret_... 형태)

Step 2 Integration 페이지 연결

  1. 연결할 Notion DB 페이지 열기
  2. 우상단 ... 메뉴 → Connections에서 Integration 선택
  3. Confirm으로 완료

Step 3 DB ID 확인

URL: notion.so/workspace/[DB_ID]?v=... 형태에서 ID 복사

Notion DB 스키마 설계 (핵심 속성 4개)

속성타입설명
TitleText각 행의 고유 식별자
StatusSelect할일 / 진행중 / 완료
DateDate생성·마감·업데이트 시각
RelationRelationTasks와 Docs 연결

Claude 단계별 지시사항

1단계 구조 파악

이 Notion DB의 구조를 분석해서 어떤 속성(컬럼)이 있는지 목록으로 알려줘.
DB ID: [복사해둔 ID]

2단계 샘플 데이터 입력

방금 파악한 구조에 맞춰 샘플 데이터 5개를 Notion DB에 직접 채워줘.

3단계 조회 스킬 자동 생성

내 Notion API 토큰은 secret_xxx 입니다.
Tasks DB ID는 abc123 입니다.
이 DB에서 Status가 할일인 항목을 조회하는 Python 스킬을 만들어줘.

완성된 자동화 흐름

지시 등록 (Notion DB에 작업 입력) ↓ Claude 감지 (DB를 읽어 할일 확인) ↓ 작업 실행 (자동으로 처리) ↓ 결과 저장 (Notion DB에 기록)

완성 기준

  • Notion DB에 토큰·ID 연결 완료
  • Claude가 구조 파악
  • 샘플 데이터 자동 입력
  • Status 필터 조회 스킬 작동

06 — 세컨드 브레인 자동 분류 저장

개요

터미널 입력을 Claude가 분석해 Notion DB 4종에 자동으로 저장하는 시스템. 트리거 키워드로 분류 위치 결정.

4가지 메모 유형과 트리거

트리거저장 위치예시
개인:Personal Tasks DB주말에 운동화 사기
업무: / 학교:Work Tasks DB내일까지 기획서 제출
메모:Notes DB다음 강의 아이디어
배움:Docs DBNotion API 필터가 자유롭다

DB 스키마 구조

  • Personal Tasks: Title, Status, Due Date, Priority
  • Work Tasks: Title, Status, Due Date, Tag
  • Notes: Title, Content, Date, Priority
  • Docs: Title, Content, Date, Topic

파일 구조

skills/

  notion-work.md          # 업무/학교 할일 저장
  notion-notes.md         # 메모 저장
  notion-docs.md          # 배움 저장
CLAUDE.md                 # 분류 규칙 지시문

CLAUDE.md 분류 규칙

## 메모 분류 규칙

사용자가 메모 입력 시:
- "개인:" 시작 → notion-personal 스킬 실행
- "업무:" 또는 "학교:" 시작 → notion-work 스킬 실행
- "메모:" 시작 → notion-notes 스킬 실행
- "배움:" 시작 → notion-docs 스킬 실행

저장 완료 후 "저장됨: [DB명]" 출력

중요도 자동 태깅

  • 급해, 오늘까지, 긴급 포함 → Priority: 높음
  • 나중에, 언젠가, 여유있을때 포함 → Priority: 낮음
  • 기타 → Priority: 보통

실습 순서

  1. Notion 저장 스킬 4개 제작 의뢰
  2. CLAUDE.md에 트리거 키워드별 분류 규칙 작성
  3. 4가지 입력으로 저장 테스트: 개인: / 업무: / 메모: / 배움:

07 — Notion을 보고 일하는 PM 에이전트

개요

PM 에이전트가 Work DB의 오늘 할 일을 조회하고, task 유형에 맞는 스킬을 실행하며, Notion Status를 직접 업데이트하는 자동화 흐름.

핵심 명령어 (사용자 입력 한 줄)

Work에서 오늘 처리해야 하는 것들 찾아서 처리해줘

→ 조회, 분류, 실행, 상태 업데이트, 완료 보고까지 트리거

필수 스킬 및 도구 (기존 스킬 재사용)

  • gws_skill.md — Google Workspace: 캘린더, Gmail, Sheets
  • naver-datalab.md — 리서치 조사
  • notion-work.md — DB 조회/업데이트

Task 유형별 행동 규칙

유형예시필요 행동도구
미팅팀장님과 킥오프 미팅 일정 확인캘린더 등록GWS Calendar
리서치경쟁사 AI 도구 도입 사례 조사트렌드 조사 후 저장Naver Datalab
문서이번달 업무 성과 정리 시트 작성구글 시트 생성GWS Sheets
이메일거래처에 진행 현황 발송이메일 작성·발송GWS Gmail

CLAUDE.md 처리 규칙

명령 수신 시:
(1) 오늘 마감일인 task 목록 조회
(2) 순서대로 처리
(3) 처리 시작 전 Status='진행중' 변경
(4) 완료 후 Status='완료' 변경
(5) 오류 시 메모에 기록

유형별 스킬 매핑:
- 미팅 → work-meeting 스킬: task명에서 일정 파악 후 캘린더 등록
- 리서치 → work-research 스킬: 키워드 조사 후 메모 저장
- 문서 → work-docs 스킬: 시트 생성 후 링크 저장
- 이메일 → work-email 스킬: 메일 작성 후 발송

유형별 스킬 제작 프롬프트

work-meeting.md

미팅 task는 캘린더에 일정 등록. task명에서 날짜·시간 파악 후 GWS calendar로 등록하고 완료 처리

work-research.md

리서치 task는 키워드 추출해 데이터랩 조사, 결과 요약을 Work DB 메모에 저장 후 완료 처리

work-docs.md

문서 task는 정리할 내용 파악 후 구글 시트 생성, 링크를 Work DB에 저장 후 완료 처리

work-email.md

이메일 task는 수신자와 용건 파악해 제목·본문 작성, GWS Gmail로 발송 후 완료 처리

4가지 검증 케이스

  1. 구글 캘린더 등록: 미팅 유형 → task명 분석 → 캘린더 등록 → Status 완료
  2. 데이터랩 조사: 리서치 유형 → 키워드 추출 → 검색량 확인 → 메모 저장
  3. 구글 시트 생성: 문서 유형 → 컬럼 구조 구성 → Sheets 생성 → 링크 기록
  4. 지메일 발송: 이메일 유형 → 제목·본문 작성 → Gmail 발송 → 상태 업데이트

완성 기준

Notion에서 Status가 "시작 전 → 진행중 → 완료"로 변경되고, 실제 캘린더·메모·시트·이메일 결과물 생성 확인

개요

폴링(Polling) 메커니즘

4. 스킬 호출 → 산출물 생성 → Status "완료"로 변경
5. 다시 대기 상태로 돌아가 반복

AI 이미지 생성 스킬 추가

API 준비

  1. platform.stability.ai 접속 후 회원가입
  2. Dashboard → API Keys → Create Key
  3. .env에 STABILITY_API_KEY=sk-xxx 저장

Claude 요청 예시

stability.ai API로 이미지 생성 스킬 만들어줘.
모델: sd3.5-flash, 입력: 텍스트 설명(한영 자동번역), 출력: output/ PNG

7단계 실습 로드맵

  1. Notion 템플릿 복제 → Integration 연결
  2. .env 설정 → NOTION_TOKEN, REHEARSAL_DB_ID, STABILITY_API_KEY
  3. 터미널 6개 실행 → PM + 담당자 5명
  4. 폴링 시작 → 담당자 5명에서 폴링 활성화
  5. 회의록 투입 → PM 터미널에 Google Docs 링크 전달
  6. 자동 처리 관찰 → Status 변화 (시작 전 → 진행 중 → 완료)
  7. 결과 확인 → Notion 메모 링크 + outputs 산출물

⏱ 완성 기준: 약 5분 안에 5개 산출물 생성, Notion 상태 모두 완료

세팅 체크리스트

  • Notion DB 복제
  • .env 3줄 입력 (NOTION_TOKEN, DB_ID, Stability API)
  • 터미널 6개 준비
  • 담당자 폴링 대기 상태 확인
