# 업무지식 에이전트 스킬

Notion 업무지식 DB의 신규 항목을 분석해 정형화된 매뉴얼 문서를 생성하고 지식베이스에 저장합니다.

---

## 입력 데이터

PM 에이전트로부터 받는 항목 구조:
```
{
  "page_id": "notion-page-id",
  "지식 제목": "노하우/매뉴얼 이름",
  "내용": "원문 전체",
  "카테고리": "응대/견적/납품/기타" // 없을 수 있음
}
```

---

## Step 1: 지식 유형 분류

내용 분석을 통해 유형 결정:

| 유형 | 판단 기준 | 문서 형식 |
|------|---------|---------|
| 응대 매뉴얼 | 고객/클라이언트 대화 포함 | Q&A 형식 |
| 견적/계약 기준 | 가격, 할증, 조건 포함 | 규칙 목록 |
| 납품 프로세스 | 단계별 순서 포함 | 체크리스트 |
| 일반 노하우 | 기타 | 자유 형식 |

---

## Step 2: Google Docs 매뉴얼 문서 생성

`gws-docs` 스킬을 호출해 정형화된 지식 문서를 생성한다.

**응대 매뉴얼 형식:**
```
제목: [응대매뉴얼] {지식 제목}

■ 적용 상황
{어떤 상황에 이 매뉴얼을 사용하는지}

■ 핵심 원칙
- {원칙 1}
- {원칙 2}

■ 응대 예시
Q: {상황}
A: {권장 응답}

■ 주의사항
- {지켜야 할 것}

■ 업데이트 이력
- {오늘날짜}: 최초 작성
```

**견적/계약 기준 형식:**
```
제목: [기준규칙] {지식 제목}

■ 적용 조건
{이 규칙이 적용되는 상황}

■ 기준 내용
- {규칙 1}: {내용}
- {규칙 2}: {내용}

■ 예외 사항
- {예외가 있을 경우}

■ 업데이트 이력
- {오늘날짜}: 최초 작성
```

**납품 프로세스 / 체크리스트 형식:**
```
제목: [프로세스] {지식 제목}

■ 처리 단계
□ Step 1: {단계명} — {설명}
□ Step 2: {단계명} — {설명}
□ Step 3: {단계명} — {설명}

■ 완료 기준
{언제 이 프로세스가 완료된 것으로 보는지}

■ 업데이트 이력
- {오늘날짜}: 최초 작성
```

---

## Step 3: Google Drive 저장

`gws-drive` 스킬로 "업무지식베이스" 폴더에 저장:
- 폴더명: "업무지식베이스/{카테고리}" (없으면 생성)
- 파일명: `[{카테고리}] {지식 제목}_{날짜}.docx`

---

## Step 4: Notion 페이지 업데이트

`mcp__claude_ai_Notion__notion-update-page`로 처리 기록:
- 내용에 추가: "에이전트처리: {오늘날짜} / Docs링크: {google_docs_url}"

---

## Step 5: 결과 보고

```
[업무지식 에이전트 처리 완료]
- 지식 제목: {지식 제목}
- 유형: {응대매뉴얼 / 기준규칙 / 프로세스 / 일반}
- Docs 문서: "{문서 제목}" 생성 완료
- Drive 저장: 업무지식베이스/{카테고리}/{파일명}
- Notion 업데이트: 완료
```

---

## 주의사항

- 기존에 동일/유사한 지식 문서가 Drive에 있으면 새로 생성하지 않고 기존 문서 업데이트 여부를 사용자에게 확인
- 민감한 계약 조건이나 단가 정보가 포함된 경우 Drive 공유 설정을 "링크 있는 사람만 보기"로 제한 권고
