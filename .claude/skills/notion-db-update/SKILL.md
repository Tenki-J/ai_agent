# Notion DB 메모 자동 분류 스킬

사용자가 입력한 문장을 분석해 5개 Notion DB 중 하나로 분류하고, 해당 DB에 페이지를 생성합니다.

---

## Step 1: 분류

### 키워드 우선 규칙 (문장이 아래 단어로 시작하면 즉시 해당 DB로 분류)

| 시작 키워드 | 분류 DB |
|---|---|
| 요청 | 업무요청 DB |
| 업무 | 실행업무 DB |
| 자료 | 자료조사 DB |
| 노하우 | 업무지식 DB |
| 개인 | 개인일정 DB |

### DB별 판단 기준 (키워드 없을 때 문장 전체를 분석)

**업무요청 DB** — 클라이언트, 상사, 팀원, 외부 담당자가 나에게 요청한 내용
- 트리거 표현: 수정해달라고, 추가 요청, 문의, 피드백, 전달 요청
- 판단 핵심: "외부 사람이 나에게 무언가를 해달라고 했다"
- 예시: "클라이언트가 오늘까지 상세페이지 문구 수정해달라고 함"

**실행업무 DB** — 내가 직접 처리해야 할 작업/업무
- 트리거 표현: 제작, 수정, 작성, 제출, 전달, 확인, 정리, 컨펌, 보고
- 판단 핵심: "내가 해야 할 일"
- 예시: "오늘 오후까지 카드뉴스 5장 수정본 전달"

**자료조사 DB** — 참고자료, 링크, 시장조사, 경쟁사 사례, 레퍼런스, 통계, 출처 정보
- 판단 핵심: "나중에 참고할 정보나 조사 내용"
- 예시: "경쟁사 랜딩페이지 후기 섹션 배치 방식 참고"

**업무지식 DB** — 반복 활용 가능한 노하우, 매뉴얼, 기준, 응대 문구
- 판단 핵심: "다음에도 써먹을 수 있는 지침이나 방법"
- 예시: "원본 파일 제공 시 기본 견적에 50% 추가금 안내"

**개인일정 DB** — 나의 개인 일정, 약속, 회의, 기념일
- 판단 핵심: "특정 날짜/시간에 발생하는 나의 이벤트"
- 예시: "팀 구성원과 15시에 회의 일정"

### 애매한 경우 처리 순서
1. 외부 사람이 요구한 내용 → 업무요청 DB
2. 내가 완료해야 할 작업 → 실행업무 DB
3. 참고하거나 조사한 정보 → 자료조사 DB
4. 반복해서 쓸 수 있는 규칙/지침 → 업무지식 DB
5. 친구, 동료, 날짜+장소 조합 → 개인일정 DB
6. 위 5가지 기준을 모두 적용해도 불명확하면 → 사용자에게 DB를 직접 확인 후 저장

## Step 2: 페이지 생성

분류 결정 후 `mcp__claude_ai_Notion__notion-create-pages` 도구로 해당 DB에 페이지를 생성합니다.

입력 문장에서 아래 정보를 추출해 속성에 채웁니다.
- **제목**: 문장의 핵심을 30자 이내로 요약
- **날짜**: "오늘", "내일", "이번 주 금요일", "15시" 등이 있으면 오늘 날짜(2026-06-27) 기준으로 절대 날짜로 변환
- **원문**: 메모/비고/내용/요약 속성에 원문 전체를 저장

## Step 3: 결과 보고

페이지 생성 후 다음을 간결하게 보고합니다.

1. 분류된 DB 이름과 그 이유 (한 줄)
2. 생성된 페이지 제목
3. 주요 속성 요약 (제목, 날짜, 상태 등)

> "→ [DB명]으로 저장했습니다. 다른 DB가 더 적합하다면 말씀해 주세요."
