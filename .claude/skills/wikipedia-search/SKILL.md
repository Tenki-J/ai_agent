  단순한 정보 질문이라도 "위키", "위키백과", "wikipedia"라는 단어가 포함되면 이 스킬을 우선 적용한다.

## 개요

`pw/wikipedia_search.py` 스크립트를 실행해 위키백과 한국어판에서 키워드를 검색하고,
첫 번째 결과 문서의 본문 요약·목차를 추출해 사용자에게 전달한다.

---

## 실행 방법

### 1단계 — 키워드 추출

사용자 메시지에서 검색 키워드를 파악한다.

- "인공지능에 대해 위키에서 알려줘" → 키워드: `인공지능`
- "위키백과에서 블록체인 찾아줘" → 키워드: `블록체인`
- "머신러닝 위키 요약" → 키워드: `머신러닝`

### 2단계 — 스크립트 실행

프로젝트 루트에서 아래 명령을 실행한다.

```bash
python -X utf8 pw/wikipedia_search.py "<키워드>"
```

- 작업 디렉토리: 프로젝트 루트 (`C:\Users\SBS\Downloads\agent ai-2`)
- `playwright`와 `chromium`이 이미 설치되어 있으므로 별도 설치 불필요
- 실행 시간: 보통 10~20초 소요

### 3단계 — 결과 파싱 및 응답

스크립트 출력에서 다음 항목을 추출해 사용자에게 보기 좋게 응답한다.

| 항목 | 설명 |
|------|------|
| 문서 제목 | 검색 결과로 이동한 위키백과 문서 이름 |
| URL | 해당 문서의 위키백과 링크 |
| 요약 | 본문 첫 5문단 (최대 800자) |
| 목차 | 문서의 주요 섹션 목록 |

---

## 응답 형식

```
## [문서 제목]

**출처:** [URL]

### 요약
(본문 요약 내용)

### 목차
1. 섹션명
2. 섹션명
...
```

## 오류 처리

| 오류 상황 | 대응 방법 |
|----------|----------|
| `ModuleNotFoundError: playwright` | `pip install playwright && python -m playwright install chromium` 실행 안내 |
| 검색 결과 없음 | 다른 키워드로 재시도 제안 |
| 타임아웃 | 네트워크 상태 확인 후 재시도 안내 |
| 요약이 비어있음 | URL을 직접 안내하고 수동 확인 요청 |
