INTRO

AI 에이전트 개념

AI 에이전트란?

질문에 답하는 것을 넘어 스스로 목표를 설정하고 계획하며 실행하는 자율 시스템입니다.

4가지 핵심 능력

  1. 환경 인식 — 파일·웹·API 탐색 및 정보 수집
  2. 자율 판단 — 데이터를 바탕으로 다음 행동 결정
  3. 도구 활용 — 코드 실행, 파일 편집, 외부 서비스 호출
  4. 반복 개선 — 결과 검증 후 목표 달성까지 자기 수정

💡 실사용 예: "매주 월요일 9시에 매출 데이터 분석 후 이메일 보고서 발송" → AI 에이전트가 전체 워크플로우를 자동 실행

일반 AI vs AI 에이전트 비교

구분일반 챗봇AI 에이전트
역할질문에 답변목표를 실행
방식즉각 응답계획 → 실행 → 검토
도구 사용제한적·없음다중 도구 적극 활용
범위단일 답변멀티스텝 프로젝트
비유잘 답하는 친구일을 처리하는 비서

에이전트 핵심 워크플로우

목표 입력 → 목표 이해 → 작업 계획 → 도구 선택 → 실행 → 결과 검증 → 수정 → 최종 결과

실생활 예시: 제주도 여행 계획

  1. 날짜 확인 → 날씨 검색 → 항공/숙소 조건 확인
  2. 관광지 후보 목록화 → 이동 경로 계산
  3. 여행 일정 작성 → 예산 요약

5가지 핵심 구성 요소

  • ① 목표 인식 — 주제·대상·필요 자료·형식·근거 파악
  • ② 계획 수립 — 목표를 서브태스크로 분해 (시장조사 → 트렌드 → 사례 → 구조 → 정제)
  • ③ 도구 사용 — 적절한 도구 선택·실행 (웹검색·캘린더·이메일·문서·코드·이미지 생성)
  • ④ 실행 및 관찰 — 실행 후 충분성 평가, 출처 신뢰도 판단
  • ⑤ 반복 개선 — 첫 결과에서 멈추지 않고 수정 사이클로 정제

02 — 보안 & 환경 설정

파일 접근 & 데이터 프라이버시

기본 쓰기 제한: 시작 디렉토리 및 하위만 접근 가능

권장 개인정보 설정

claude.ai/settings/data-privacy-controls 접속

  • 위치 메타데이터 수집 비활성화
  • 데이터 개선 프로그램 거부

settings.json 설정

위치 (우선순위 순)

  1. ~/.claude/settings.json (PC 전체 적용)
  2. .claude/settings.json (프로젝트 팀 공유)
  3. .claude/settings.local.json (개인 전용)

권한 규칙 문법

{
  "permissions": {
    "rules": [
      {"deny": "Bash(rm -rf *)"},
      {"allow": "Bash(npm run *)"},
      {"deny": "Read(./.env)"}
    ]
  }
}

평가 순서: deny → ask → allow

규칙 형식 예시

형식의미
Tool도구 전체 차단/허용
Tool(specifier)특정 조건만 적용
Bash(npm run *)npm 명령만 허용
Read(./.env).env 읽기 차단
Bash(rm -rf *)재귀 삭제 차단

권한 모드 (Shift+Tab으로 전환)

  1. 일반 모드 (기본) — 각 작업 전 확인 요청
  2. 자동 승인 편집 — 편집 자동 승인, 터미널만 확인
  3. 플랜 모드 — 제안된 옵션 중에서 선택

YOLO 모드 (모든 권한 자동 승인)

claude --dangerously-skip-permissions

종료: /exit 또는 Ctrl+C 두 번

모델 선택 (/model)

모델특징
Haiku 4.5가장 빠름, 단순 작업
Sonnet 4.6기본 추천, 코딩·자동화
Opus 4.5최고 성능, 깊은 추론

포그라운드 vs 백그라운드 실행

포그라운드 (기본값)

  • Claude가 완료까지 대기
  • 실행 중 다른 프롬프트 입력 불가
  • 기본 타임아웃: 2분

백그라운드 (Ctrl+B)

  • 비동기 실행, 태스크 ID 반환
  • 동시에 다른 프롬프트 입력 가능
  • 적합한 작업: npm install, docker build, 서버

태스크 관리

Ctrl + T        # 태스크 보기 전환
Ctrl + F        # 전체 강제 종료

훅(Hooks) 시스템 — 18개 이벤트 포인트

특정 워크플로우 시점에 스크립트를 자동 실행하는 시스템

차단 이벤트 (exit code 2 사용 가능)

  • PreToolUse — 도구 실행 전
  • UserPromptSubmit — 프롬프트 처리 전
  • PermissionRequest — 권한 요청 시점
  • Stop — 응답 완료 전
  • SubagentStop — 서브 에이전트 종료
  • TeammateIdle — 팀원 유휴 상태 전
  • TaskCompleted — 태스크 완료 표시 전
  • ConfigChange — 설정 파일 변경
  • WorktreeCreate — 워크트리 생성 전

관찰 이벤트 (차단 불가)

  • SessionStart / SessionEnd
  • InstructionsLoaded
  • PostToolUse / PostToolUseFailure
  • Notification
  • SubagentStart
  • PreCompact
  • WorktreeRemove

실행 흐름

User Prompt → UserPromptSubmit Hook → PreToolUse Hook → Tool 실행 → PostToolUse Hook → Stop Hook → 응답

실습 예시 — PC 알림 훅

settings.json에 Claude 응답이 완료될 때마다 BurntToast로 PC 알림이 뜨는 Hook 추가해줘

06 — MCP (Model Context Protocol)

MCP란?

AI를 외부 서비스와 연결하는 표준 프로토콜 (USB-C와 같은 개방형 표준)

MCP 없이 → 복사 → 붙여넣기 → 수동 관리
MCP 있으면 → "Notion 정리해줘" → Claude가 직접 처리

지원: Claude, ChatGPT, Cursor (공개 표준)

MCP 설치 방법

HTTP 방식 (원격 권장)

claude mcp add --transport http [name] [URL]

Stdio 방식 (로컬 PC 실행)

claude mcp add --transport stdio [name] -- npx ...

관리 명령어

claude mcp list
claude mcp remove [name]
/mcp          # 세션 내 관리

범위: local (현재 프로젝트) | project (팀 공유) | user (PC 전체)

Trivago MCP — 호텔 검색

등록

claude mcp add --transport http trivago https://mcp.trivago.com/mcp

주요 기능

  • 국가/도시/날짜/인원 기준 검색
  • 가격·위치·후기 비교
  • 예산·평점·시설 필터
  • 인증 불필요 — 즉시 사용 가능

실습 프롬프트

  • Image.new() — 캔버스 생성
  • ImageDraw — 도형·텍스트 그리기

  • img.crop() — 자르기

실습 요청

pillow로 1080x1080 카드뉴스 이미지 만들어줘.

  4. 스킬 변환 요청 ("이걸 /cardnews 스킬로 만들어줘")
  5. 인수 활성화 ("배경색, 제목, 본문을 인수로 받도록")

디스코드 봇 설정

Step 1 봇 생성

  1. discord.com/developers/applications 접속
  2. New Application 클릭
  3. Bot 탭 → Reset Token → 복사

Step 2 Intent 활성화

Privileged Gateway Intents → Message Content Intent ✓

Step 3 OAuth2 설정

  1. OAuth2 탭 → URL Generator
  2. "bot" 체크
  3. "Read/Send Messages" 체크
  4. 생성된 URL 복사 → 서버에 봇 초대

토큰 관리: .env에 저장 (절대 하드코딩 금지)

디스코드 플러그인 설치

/mcp
→ discord 선택
→ Enable

Step 4 토큰 저장

echo "DISCORD_BOT_TOKEN=YOUR_TOKEN" > ~/.claude/channels/discord/.env

Step 5 DM 페어링

  1. 봇에게 DM 전송 → 페어링 코드 수신
  2. Claude 터미널에 코드 붙여넣기

Step 6 서버 채널 등록

  1. Discord: 설정 → 고급 → 개발자 모드 ✓
  2. 채널 우클릭 → 채널 ID 복사
  3. Claude에서 요청:
/discord:access group add <CHANNEL_ID>

MCP vs 플러그인 비교

기능MCP (stdio)플러그인 (Official)
설치git clone + 빌드자동 설치
사용 가능 도구2개 (읽기/보내기)5개 (reply/fetch/react/edit/download)
멘션 필터없음있음
파일 첨부없음있음
이모지 반응없음있음
채널 접근DM 제한DM + 서버 (access.json)

결론: 플러그인 = 공식 지원 + 더 많은 도구 + 실시간 = MCP보다 우수
