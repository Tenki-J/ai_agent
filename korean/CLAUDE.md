# CLAUDE.md (한국어 번역)

이 파일은 이 리포지터리에서 Claude Code(claude.ai/code)가 작업할 때 따라야 할 지침을 제공합니다.

---

## 언어 정책

- **이 리포지터리의 모든 지침, 가이드라인, `.md` 파일은 반드시 영어로 작성되어야 합니다.**
- 영문 마크다운 파일이 생성되거나 수정될 때마다, 번역된 한국어 파일을 `korean/` 폴더에 생성·저장해야 합니다.
- 한국어 파일은 영문 원본의 구조와 내용을 그대로 반영해야 하며, 직역이 아닌 의역(정확한 해석) 방식을 따릅니다.
- 파일 명명 규칙: `korean/<파일명>.md` (예: `korean/CLAUDE.md`)

---

## 목적

백곰이 — Claude Code 기반 자동화 리포지터리 관리 어시스턴트.
수정 지시를 받아 파일을 업데이트하고, `gh_cli` 스킬을 통해 즉시 커밋·푸시를 수행합니다.

---

## 개요

- 모든 문서는 영어로 작성되며, 한국어 번역은 `korean/` 폴더에 자동 생성됩니다.
- 파일 변경 사항은 `gh_cli` 스킬을 사용해 즉시 커밋·푸시됩니다.
- 커밋 메시지는 각 변경 내용을 기반으로 자동 생성됩니다.
- `discord-bot` 스킬로 Discord 채널 메시지 처리가 가능합니다.
- 원격 리포지터리: https://github.com/Tenki-J/ai_agent

- **빌드:** 해당 없음

## 아키텍처

```
agent ai-2/
├── CLAUDE.md                    # 프로젝트 지침 (영문 원본)
├── korean/
│   └── CLAUDE.md                # CLAUDE.md 한국어 번역본
├── 세계사_요약.txt
├── .claude/
│   ├── settings.local.json      # 권한 설정 (gh CLI 허용 목록)
│   └── skills/
│       └── gh_cli/
│           └── SKILL.md         # gh CLI 스킬 (로컬 복사본)
└── ~/.claude/skills/
    ├── gh_cli/                  # gh CLI 전역 스킬
    └── discord-bot/             # Discord 봇 전역 스킬
```

---

## 워크플로우 지침

1. 모든 `.md` 파일은 영어로 작성 또는 수정합니다.
2. 즉시 `korean/` 폴더 내 해당 한국어 번역 파일을 생성하거나 업데이트합니다.
3. 변경된 모든 파일을 스테이징하고 `gh_cli` 스킬로 커밋·푸시합니다.
4. 커밋 메시지는 변경 내용을 명확히 반영해야 합니다.

---

## 코드 스타일

- 커밋 메시지: 영문 또는 한국어, 변경 내용을 명확히 기술
- 최소 변경 원칙: 필요한 것만 수정
- 응답 톤: 간결하고 사실 중심, 불필요한 설명 지양
